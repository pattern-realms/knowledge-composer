# 🌌 Knowledge Composer

> **A desktop context development environment for the Knowledge Cosmos™ Ecosystem.**

Knowledge Composer™ is a local-first macOS environment for creating, exploring, and sharing context-based publications, simulations, and games. It enables developers, authors, and world builders to organize deep-context trees of Markdown and media into dynamic, interactive element grids. Animation creators can view and test animation properties and triggers. Stories can be told by positioning media and web content across a paintable game map. Simulations are powered by a lightweight scripting engine, and the underlying element model provides a robust structure for managing ideas, input, analysis, and publications which are made available via an integrated web server. Experiences can be shared as complete samples or as curated, content-free imprint flows. With pervasive element-oriented substitution the system eliminates content redundancy. By operating alongside AI development environments, the file-system-as-repository allows generated assets to be fully addressable across the Knowledge Cosmos. Element addressability and publishing makes AI output reliable, reusable, and reproducible. By synthesizing folders of Markdown, animation, and media with scripted behaviors in a grid of elements, Knowledge Composer empowers users to build intricate solutions and publications. Enter the Knowledge Cosmos today with Knowledge Composer.

## 🚀 Knowledge Composition Made Simple

Knowledge Composer provides a complete technical stack for creating advanced solutions:

* **Knowledge Composer:** Context editor and organizer for composing elements with visual designs to create a seamless flow from ideas and input to published documents and interactive simulations.
* **Element Castle Model™:** A universal pattern language where every piece of data is represented as an addressable **Element** object composed of markdown text and properties, visual design, animations, media, and guides.
* **Element-Oriented Substitution:** Effortlessly embed linked values across a massive text architecture using intuitive Markdown syntax: `~payload~` and `~verse~` (overloading the standard strikeout tag). Generate once, use anywhere.
* **Gameblazer™ Simulation Engine** An event-driven dispatch queue that allows tiles to communicate, process logic, and state with interactive control of real-time graphical animations and media.
* **Darthawk™ Scripting Gateway:** Write local Dart scripts inside Element directives to trigger system operations, read and write files in the sandbox, perform HTTP requests, and interact with other elements.
* **Totally Local Markdown Repository:** Every Universe, World, and Realm is saved as Markdown with YAML directly on the local file system. Modify models in the Knowledge Composer, or edit files with any AI-enabled development environment such as Anitgravity, VS Code and Claude. The file system is your database.
* **Effortless Sharing and Discovery:** Publish content instantly in the integrated web server, with automated or link-based discovery.  Instantly merge updates and expansions from remote content nodes. Reprint a universe, world or realm with one click.
* **Show Your Work** Publish the entire context and creation path used to build a document or simulation. Provide content, full sample reprints, or flow imprints to share and evolve ideas in a cosmos of creativity.

## 🛠️ Ecosystem of Realms of Elements

Knowledge Composer creates an ecosystem where your local foundry is a factory for creating elements in a realm in a world in a universe.

```text
Ecosystem ──► Origin (Your Node) ──► Foundry (Your Factory) ──► Universe ──► World ──► Realm ──► Element
```

This structure is reflected in the file system and each world or realm can be fully self contained and transportable.
